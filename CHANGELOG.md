# Changelog

Versions follow [semantic versioning](https://semver.org/). The version here always matches `chaos_overdrive/mod.json`.

## 1.0.0 (2026-11-02)

First release. Needs CHAOS LAB with Mod API 1.1.

- A menu on F6 with 14 categories, search, active effect indicators, and per-function and full resets.
- Player, movement, physics, NPC, weapon, vehicle, world, spawning, visual, time, teleport and experiment controls. See [docs/FEATURES.md](docs/FEATURES.md).
- Profiles, with import and export of settings as JSON, rebindable keys, and a menu size setting.
- Off by default. Everything it changes is undone when it's disabled.
